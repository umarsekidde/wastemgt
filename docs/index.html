WMBS

Waste Management & Billing System

This is a Node.js application. InfinityFree cannot run it (it only hosts static files and PHP).

To use the login and full app:

  1. Deploy this project to a Node.js host (e.g. Render, Railway, Cyclic).
  2. Use a free MySQL database (e.g. from the same host or FreeMySQLHosting).
  3. Open your app URL; the login page will be at /auth/login.
